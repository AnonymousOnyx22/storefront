$ what it does

Everything a game, a launcher or a website can learn about your machine — replaced with a believable one, all at once.

  • 01 new machine identity
    the name, serial and system id your PC reports are swapped for a clean set that matches a real manufacturer.
  • 02 new disk identity
    your drive's serial and volume id change too, so storage can't be used to link you back.
  • 03 new network identity
    a fresh hardware address, from the same vendor as the rest of the profile, so nothing looks pasted on.
  • 04 leftovers cleaned
    the traces windows keeps about your old setup are cleared, so the previous identity stops showing up.
  • 05 one coherent set
    board, disk and network are generated together as one believable machine — not three random strings.
  • 06 undo any time
    every original value is saved. restore puts your machine back exactly as it was.

$ questions

how do I get my key?

It's emailed to the address you enter at checkout, usually within a minute. Nothing appears on screen, so keep that email — it's also how you sign in later.

do I need an account?

No. Your email and your key are the account. Sign in on the my key page with those two things. There's no password to forget.

does it need to be running all the time?

No. You run it once, press spoof, and restart. It doesn't sit in the background or start with Windows.

will it survive game updates?

Yes. Game and anticheat updates don't undo it. A major Windows feature update occasionally does, and then you just run it again.

can I move my key to a new PC?

Yes, using a reset from your my key page. 1 day is unlimited spoofs for 24 hours, 7 days includes one reset, 30 days includes three, 90 days includes six, and permanent is unlimited.

my antivirus complains. is that normal?

Yes, and it's expected. Anything that changes hardware identity looks suspicious to antivirus. Add the install folder to your exclusions before running. A new installer gets this treatment whether it is signed or not.

what do I need?

Windows 10 or 11, 64-bit, UEFI. Any reasonably modern PC. Not supported on 32-bit, ARM, or legacy BIOS machines.

refunds?

24 hours, and only if the key hasn't been used on a machine yet. Once it's bound, it's spent. Full details in the terms.
