basalt

External overlay for Rust. In development.

in development

$ what it is

Basalt is an external engine for Rust. It reads the game process from outside, resolves live offsets, and renders ESP, aimbot and movement features on a capture-excluded DX11 overlay. Nothing is injected into the game.

The overlay sits on top of the game but is invisible to screen capture, streaming software and anti-cheat screenshots. The menu opens with INSERT and everything is configurable in real time.

$ features

  • player ESPboxes, skeletons, health bars, names, distance, held item, flags. separate colours for visible/hidden, configurable render distance
  • NPC ESPscientists and animals with boxes, skeletons, names, distance. independent toggle and render distance
  • aimbotsilent aim (no mouse movement), bone selection (head/chest/leg), FOV circle, visibility check, dynamic FOV, target filtering (wounded, scientists, sleepers, teammates, safezone)
  • weaponsrecoil control, spread control, no shotgun spread, fast bullets, force auto, instant eoka, reload indicator
  • movementspeed multiplier, bunny hop, spiderman, noclip, infinite jump, omni sprint, air control, gravity control, no fall damage
  • miscbright night, custom time of day, enemy alerts, battle indicator, instant loot, instant revive, custom sky colours
  • overlayDX11 capture-excluded window (WDA_EXCLUDEFROMCAPTURE), invisible to OBS, Discord, anti-cheat screenshots
  • menu5-tab ImGui menu (visuals, combat, movement, misc, config). INSERT to toggle. everything configurable live, settings saved to INI
  • crosshaircustom crosshair with style, size and colour options. optional rainbow mode
  • offsetsauto-updated after each Rust patch via Il2CppDumper pass

$ how it works

  • 01 external read. basalt reads game memory through a mapped driver via DeviceIoControl. no handle on the game process, no DLL injection, no hooks inside Rust.
  • 02 offset resolution. after each Rust update, offsets are re-derived from an Il2CppDumper pass and pushed. the client loads them from config on start, with compiled fallbacks.
  • 03 capture-proof overlay. a DX11 window composited with DirectComposition and WDA_EXCLUDEFROMCAPTURE. per-pixel alpha transparency. screen recordings, streams and screenshots see the game, not the overlay.
  • 04 silent aim. no mouse movement. basalt computes the direction to the target bone and rewrites the shot vector before the server sees it. the anti-cheat sees a normal shot.
  • 05 one exe, no install. run basalt.exe, open Rust, press INSERT. close it when you are done. settings save to an INI beside the exe.

$ questions

When does it release?

No fixed date. It ships when testing is done. Join the Discord for announcements.

Is it detected?

External tools have a different detection surface than injected ones. Basalt reads memory externally and renders on a separate, capture-excluded window. Detection status will be tracked on the status page once it goes live.

Does it work with EAC?

Rust uses Easy Anti-Cheat. Basalt is designed around that. Specific compatibility is verified during testing.

Can I use it with slate?

Yes. Slate changes your hardware identity, basalt provides in-game features. They are separate products with separate keys but designed to work together.
