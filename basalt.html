$ how it works

Five layers from driver to screen. Nothing touches the game process.

  • 01 external read. basalt reads game memory through a mapped driver via DeviceIoControl. no handle on the game process, no DLL injection, no hooks inside Rust.
  • 02 offset resolution. after each Rust update, offsets are re-derived from an Il2CppDumper pass and pushed. the client loads them from config on start, with compiled fallbacks.
  • 03 capture-proof overlay. a DX11 window composited with DirectComposition and WDA_EXCLUDEFROMCAPTURE. per-pixel alpha transparency. screen recordings, streams and screenshots see the game, not the overlay.
  • 04 silent aim. no mouse movement. basalt computes the direction to the target bone and rewrites the shot vector before the server sees it. the anti-cheat sees a normal shot.
  • 05 one exe, no install. run basalt.exe, open Rust, press INSERT. close it when you are done. settings save to an INI beside the exe.

$ questions

When does it release?

No fixed date. It ships when testing is done. Join the Discord for announcements.

Is it detected?

External tools have a different detection surface than injected ones. Basalt reads memory externally and renders on a separate, capture-excluded window. Detection status will be tracked on the status page once it goes live.

Does it work with EAC?

Rust uses Easy Anti-Cheat. Basalt is designed around that. Specific compatibility is verified during testing.

Can I use it with onyx?

Yes. Onyx changes your hardware identity, basalt provides in-game features. They are separate products with separate keys but designed to work together.
