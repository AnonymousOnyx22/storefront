$ internal vs external

obsidian (internal) and basalt (external) take different approaches. pick whichever fits.

  • renderingobsidian draws through the game engine. basalt draws on a separate DX11 overlay
  • chams + glowinternal only. material overrides require access to the game's render pipeline
  • world ESPinternal only. ore nodes, stashes and traps are not in the networked entity list an external reads
  • aimbotobsidian moves the mouse directly. basalt uses silent aim (rewrites shot direction)
  • detectionexternal has a smaller footprint (no code in game). internal has deeper access but more surface area
  • capturebasalt overlay is excluded from screen capture. obsidian renders in-game, so it shows in recordings unless toggled off

$ how it works

Four steps from injector to game.

  • 01 manual map injection. the injector maps the DLL into the Rust process without calling LoadLibrary. no entry in the loaded module list, no file path on disk after injection.
  • 02 hook installation. obsidian hooks into the game's update loop and render pipeline. ESP and chams draw through the game's own renderer. weapon mods intercept fire events directly.
  • 03 direct memory access. no driver, no DeviceIoControl. obsidian reads and writes game structures from inside the process. lower latency, more data available.
  • 04 offset updates. after each Rust patch, updated offsets are pushed. the client loads them on inject, same as basalt.

$ questions

When does it release?

No date announced. Obsidian is in early development. Join the Discord for updates.

What is the difference between obsidian and basalt?

Basalt is external: it reads memory from outside and draws on a separate overlay. Obsidian is internal: it injects into the game and renders through the game engine. Internal gives you chams, glow, world ESP and direct aim. External gives you a capture-proof overlay and a smaller detection surface.

Can I use obsidian with onyx?

Yes. Onyx changes your hardware identity. Obsidian provides in-game features. They are separate products with separate keys.

Can I use obsidian with basalt?

Running both at the same time is not recommended. Use one or the other per session.

Will it be detected?

Internal tools have a larger detection surface than external tools. Obsidian uses manual mapping and cleans up after injection. Detection status will be tracked on the status page once it goes live.
